# Learning log

One entry per step of the project, written for the owner, so that by the end this
folder reads as a short textbook on fine-tuning and evaluating a small model. Each
entry has the same shape: the lesson before the step, what we did, the terms that
came up, what you just learned, and a few check questions.

This is separate from `notebook/`, which records individual training runs.
