# Practice data: attribution and terms

`source/scenarios.json` is the AI Act Evaluation Benchmark by Athanasios Davvetas,
Michael Papademas, Xenia Ziouvelou and Vangelis Karkaletsis (NCSR "Demokritos" and
Panteion University), arXiv 2603.09435, downloaded from
github.com/davidath/ai-act-evaluation-benchmark at commit
d323167f5597dfd9365b376c9afe7b0e414eb81a on 2026-10-27.

- The scenario data is licensed Creative Commons Attribution 4.0 International
  (stated inside `scenarios.json`). `source/LICENSE` is the repository's Apache 2.0
  licence for its code, kept for completeness; no code was downloaded.
- The authors state the scenarios were generated by a language model (gpt-oss-120b)
  with partial human checks and still need legal-expert validation.

How this project uses it: practice only (requirement LG-3). The files in `mlx/` and
`heldout.jsonl` are derived by `python -m lab.practice prepare`: a short description
built from each scenario's fields, and a target of tier, articles and a templated
reason. The benchmark's obligation lists are deliberately not used. "limited" is
mapped to "transparency-only". None of these scenarios is, or will be, part of this
project's gold set.
