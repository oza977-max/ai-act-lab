## Deviations from Spec
- The spec asks for two examples per label; there are 18 (three for most labels) because reviews exposed rules that needed an example to be unambiguous.
- `needs-human-review` "rests on" reads "none: a project label" rather than an article, because the Act has no such label (LS-1 asks for an article; citing one would be decoration). The test allows this one row.
- Article 50(2) is read to exclude summaries, extracts, transcriptions and format conversions of supplied material; marked provisional in the text.

## Surfaced Requirements
- The guideline sets conventions the law leaves open (Annex III step convention, 50(2) reading, safeguard situations, citation format for `annex_i_legislation`). P3 gold tooling may want to check `annex_i_legislation` strings against the format.

## Retrospective
The draft passed its own tests on the first try, and the tests were the weak point: they checked shape, not consistency. The reviewers found that examples broke the guideline's own rules, and the lasting fix was tests that every example obeys each rule. Seven passes is more than usual. Each round tightened a rule that two careful readers could otherwise apply differently, which is the property a gold set needs.
