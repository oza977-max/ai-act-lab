## Deviations from Spec
- `sheet` is a third command beside `check` and `build`; the spec's encoding rule ("cells written by Claude ... prefixed with an apostrophe") implies Claude writes sheets with code.
- `check` also refuses: final columns filled under accept or doubt; a change identical to the draft; proposed columns edited; a guideline version that differs from the draft's.
- The escape set adds tab and carriage return to `=`, `+`, `-`, `@` (OWASP).
- `owner_note` stays in the sheet; the gold case shape has no field for it.

## Retrospective
Every review round found the same kind of problem: a place where an ordinary spreadsheet habit, or an ordinary slip, would either lose the owner's work silently or lock them out. Silent loss is the worst outcome, so the rule became: any surprise is reported by case id, and nothing Claude writes can reach the owner unless it will read back unchanged.
