# Build Prompt: P3-C01 — Gold tooling

## Chunk Summary
`lab/gold.py`: `sheet` writes a review sheet (CSV, opened in Numbers) from Claude's draft file; `check` validates a filled sheet and never edits it; `build` turns the checked sheets into `data/gold/gold-v{N}.jsonl` and its metadata, refusing while a doubt remains or a quota is missed. About 1.5 hours. Tested on small fixture sheets and a generated 100-case set.

## Spec Excerpt
- Review sheet columns: `id, description, tags, proposed_tier, proposed_route, proposed_area, proposed_point, proposed_legislation, proposed_art50, proposed_articles, proposed_review_reason, proposed_reason, decision, final_tier, final_route, final_area, final_point, final_legislation, final_art50, final_articles, final_review_reason, final_reason, owner_note, guideline_version`.
- Encodings: UTF-8 (BOM accepted); booleans `true`/`false`; lists separated by `;`; empty cell means none; cells written by Claude beginning `=`, `+`, `-`, `@` prefixed with an apostrophe.
- `check`: decision `accept`/`change`/`doubt`; `change` → final columns form a valid record; `accept` → proposed columns do; 60 to 200 words; tags from the vocabulary; no delimiter strings; guideline version matches the guideline header; a description altered by the spreadsheet (compared with the draft file) is reported. Never edits.
- `build`: refuses while any `doubt` remains; copies accepted proposals into the gold record; keeps the full draft; checks GS-1 counts, GS-3 area coverage, GS-4 tag quotas and one guideline version; reports the share changed; sets `never_train`; writes `gold-v{N}.jsonl` and `gold-v{N}.meta.json` (build date, hash, guideline version).
- Gold case (cross-cutting): `id` (`GC-001`…), `description`, `gold`, `draft`, `tags`, `guideline_version`, `owner_decision`, `never_train`. The evaluation's `load_gold` reads it.
- GS-1 spread: prohibited 10, Annex III 30, Annex I 5, transparency-only 20, minimal 20, needs-human-review 10, out-of-scope 5. GS-3: each Annex III area 3 or more. GS-4: boundary 15+, art6-3 5+, hidden-instruction 5+.

## Design notes
- Draft file (Claude's, the reference for "altered by the spreadsheet"): `data/gold/drafts/batch-{NN}.jsonl`, one line per case: `id`, `description`, `tags`, `draft` (a record), `guideline_version`.
- TC-GS-2-03 (real organisation names) is enforced by the confidentiality pre-commit hook, not by `gold check`.

## Framework Reference
