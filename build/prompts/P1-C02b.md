# Build Prompt: P1-C02b — Practice fine-tune (owner-run; LG-3)

## Chunk Summary
Convert the public AI Act Evaluation Benchmark (339 scenarios, CC-BY-4.0, pinned commit d323167f) into training examples; hold out 20 cases (5 per label) for a before-and-after look and 32 (8 per label) for validation; record untrained answers; the owner runs one LoRA training with `mlx_lm lora` and compares answers after. Practice only: no numbers decide anything; benchmark scenarios never enter the gold set; adapters are not committed.

## Framework Reference (mlx-lm 0.32.2)
- Data: directory with `train.jsonl`, `valid.jsonl`, `test.jsonl`; chat lines `{"messages": [{"role": "user", ...}, {"role": "assistant", ...}]}`; `--mask-prompt` trains on the answer only.
- Training: `python -m mlx_lm lora --model <path> --train --data <dir> -c <yaml> --adapter-path <dir>`; YAML keys include `lora_parameters: {rank, scale, dropout}`, `num_layers`, `batch_size`, `iters`, `learning_rate`, `steps_per_eval`, `steps_per_report`, `val_batches`, `seed`, `mask_prompt`.
- Loading with an adapter: `mlx_lm.load(path, adapter_path=...)`.
- Chat format is identical in training and inference for this model (empty think block).
