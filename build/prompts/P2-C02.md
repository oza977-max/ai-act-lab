# Build Prompt: P2-C02 — Prompt build

## Chunk Summary
`python -m lab.prompt build` generates the zero-shot prompt `prompts/zero-shot-v{N}.txt` from the approved guideline and the record vocabularies in `lab/records.py`, stamping the guideline version. Prompt v1 is committed. A test checks the prompt matches the guideline. About 45 minutes.

## Owner decision (2026-10-27)
- **D-PR-1 Prompt size.** All the rules, no worked examples: the sections "The six labels", "Decision order", "Article 50 in short", "When the description is silent", "The Article 6(3) exception", "When to say needs-human-review" and "The answer record" (about 4,700 tokens with the Qwen3.5 tokenizer). Core-only (about 2,800) and rules-plus-examples (about 8,200, not zero-shot) were offered and declined.
